# 产品需求文档（PRD）

## 1. 产品概述

### 1.1 项目名称

浏览器书签清理与归档器

### 1.2 当前状态

- 需求、技术架构、数据与同步边界、核心交互规则已完成冻结
- 已有真实工程底座：`T01` 已建立 Vite + React + TypeScript + pnpm 的最小可执行 scaffold
- 已有真实扩展运行壳：`T03` 已建立 MV3 manifest、独立扩展页面入口和五区工作区
- 已落地启动阶段的本地草稿恢复、浏览器书签读取导入、本地持久化、规范化草稿图谱、基础节点编辑与拖拽移动
- 当前仍未落地浏览器覆盖写回、WebDAV 同步与恢复、本地备份与撤销覆盖恢复等后续能力
- `tmp/ui/` 只作为视觉与交互参考资产，禁止直接复用其中代码

### 1.3 问题陈述

浏览器原生书签管理在面对大规模书签、重复 URL、频繁整理和结构调整时，操作效率低、结构感弱、缺乏版本化能力，也难以安全地进行覆盖式整理与恢复。

### 1.4 解决方案

构建一个 Chrome 扩展，以独立扩展页面承载思维导图式书签工作区。扩展直接读取当前浏览器书签，将其映射为可编辑草稿，并通过 WebDAV 提供书签快照与草稿快照的版本化保存、恢复与同步能力。

## 2. 成功标准

说明：以下成功标准是首版冻结目标，不代表当前仓库已经全部实现。

- 用户可以直接读取当前 Chrome 书签并在思维导图中查看
- 用户可以顺滑地完成单节点编辑、新增、拖拽移动、删除和撤销
- 用户可以将浏览器书签或思维导图草稿同步到 WebDAV，并各自保留最近 5 个版本
- 用户可以从 WebDAV 覆盖恢复到浏览器书签或当前草稿，并在覆盖前自动获得对应对象的本地单份回滚备份
- 用户可以快速识别重复 URL，并通过搜索与过滤聚焦相关节点
- 首版所有用户可见前端文案均为中文，同时后续接入多语言时不需要推倒重做界面结构

## 3. 产品形态

- 平台：Chrome 扩展
- 主工作区：独立扩展页面
- 首版浏览器范围：Chrome
- 首版界面语言：中文
- 后续扩展：保留 Firefox 支持空间
- 云端能力：用户自带 WebDAV，不建设自有账号后端

## 4. 目标用户与核心场景

### 4.1 目标用户

- 长期维护大量书签的个人用户
- 对整理效率和操作流畅度有明显要求的重度浏览器用户

### 4.2 核心场景

- 查看当前浏览器书签整体结构
- 快速发现重复 URL
- 在图谱中直接整理书签结构
- 将整理结果显式同步回浏览器书签
- 将浏览器书签或草稿版本备份到 WebDAV
- 从云端版本恢复当前浏览器书签或当前草稿

## 5. 核心用户故事

- 作为用户，我希望直接读取当前浏览器书签，而不是手动导入 HTML，这样我可以立即开始整理
- 作为用户，我希望书签以思维导图形式展示，这样我能更直观地理解层级结构
- 作为用户，我希望可以双击编辑节点、拖拽移动节点、直接删除节点，这样整理过程更顺手
- 作为用户，我希望所有修改先只作用在草稿上，这样我可以整理好之后再决定是否同步到浏览器书签
- 作为用户，我希望可以将书签和草稿分别同步到 WebDAV，并保留最近 5 个版本，这样我能有云端备份和版本回溯能力
- 作为用户，我希望覆盖恢复前自动生成本地回滚备份，这样误恢复后还能撤回

## 6. 功能需求

说明：本节描述冻结功能目标。当前代码已经落地启动导入、本地恢复、规范化草稿图谱、基础编辑和拖拽移动；未明确写成“当前已实现”的其余能力，仍应视为后续目标。

### 6.1 书签读取与展示

- 直接读取当前 Chrome 浏览器书签树
- 主工作区始终展示当前思维导图草稿，而不是直接把页面表达为浏览器实时书签编辑面板
- 使用思维导图形式展示书签树
- 支持节点折叠/展开
- 节点展开/折叠状态本地持久化，不进入云端同步
- 思维导图布局坐标本地持久化，不进入云端同步
- 默认初始布局必须美观、舒适、可直接操作
- 提供“一键自动归位”按钮，将界面恢复到推荐舒适布局

### 6.2 节点信息与重复识别

- 节点悬浮时显示 URL 信息
- 若存在重复 URL，悬浮层采用混合模式展示：
  - 显示重复总数
  - 直接显示前 2 条重复路径
  - 其余项通过“展开更多”查看
- 内部可使用稳定 ID 进行识别、同步和恢复，但 ID 不在界面直接展示

### 6.3 节点编辑

- 双击节点进入编辑模式
- 目录节点可编辑标题
- 网页节点可编辑标题和 URL
- 编辑已有节点时，节点类型不可修改

### 6.4 新增节点

- 单击选中节点后按 `Enter` 进入新增流程
- 单击选中节点后按 `Shift + Enter` 进入同级新增流程
- 新增节点时，在新增表单中选择节点类型：
  - 目录节点
  - 网页节点
- 节点类型对应校验规则：
  - 目录节点不能填写 URL
  - 网页节点 URL 不能为空

### 6.5 移动与删除

- 节点支持拖拽移动到其他目录节点下
- 节点默认支持直接删除；当删除拥有多个直接子节点的目录节点时，需要二次确认
- 删除对象包含该节点及其子树

### 6.6 撤销历史

- `Ctrl+Z` 只作用于思维导图草稿编辑
- 每一次思维导图内容变化都记为一条本地历史
- 每次按下 `Ctrl+Z` 回退一步编辑历史
- `Ctrl+Z` 不负责回退“同步到浏览器书签”这类外部写操作

当前状态：

- undo patch contract 已冻结
- `Ctrl+Z` 执行链路已接入 draft-only 草稿撤销

### 6.7 操作提示可见性

- 界面保留持续可见、低干扰的“操作提示说明区”
- 操作提示说明区默认始终可见，但视觉上不应抢占主图谱注意力
- 操作提示说明区保持半透明低干扰样式，避免不必要的草稿区数据遮挡
- 操作提示说明区以“一行一条”的形式同时展示鼠标操作与键盘操作
- 当前实现中，操作提示区固定在当前可视画布右上角；画布顶边滚动进入视口顶部后，提示区继续贴住视口保持可见
- 首版必须至少完整展示以下 6 条核心操作提示：
  - 单击：选中节点
  - 双击：编辑节点
  - 拖拽：移动节点
  - `Enter`：新增子节点
  - `Delete / Backspace`：删除节点
  - `Ctrl+Z`：撤销上一步编辑

当前实现补充了更多已落地快捷操作：

- `Shift + Enter`：新增同级节点
- `↑ / ↓`：调整当前层级顺序
- `←`：提升一级目录层级
- 搜索框 `Enter`：进入普通搜索结果导航
- 搜索框 `↑ / ↓`：循环切换当前搜索聚焦结果

### 6.8 搜索与聚焦

- 提供基础搜索能力，支持按标题或 URL 搜索节点并定位结果
- 提供重复 URL 过滤 / 聚焦能力

当前状态：

- 搜索条在存在当前草稿时已启用
- 标题 / URL 搜索当前基于草稿图谱派生，不匹配路径文本或内部 ID
- 普通搜索在输入时保持图内高亮，不会自动聚焦；按 `Enter` 后才会聚焦首个结果，并可用 `↑ / ↓` 循环切换当前搜索聚焦节点
- “仅看重复项”会切换到按相同 URL 分组的重复聚焦视图，并与当前搜索词组合工作

### 6.9 文案与语言策略

- 首版前端所有用户可见内容均使用中文展示，包括按钮、表单标签、状态提示、错误提示、空态提示、确认文案与操作提示说明
- 文案组织方式需保留后续多语言扩展空间，避免把展示文本零散硬编码在各个组件逻辑中

## 7. 数据与同步模型

### 7.1 数据层次

系统包含以下核心对象层：

- 浏览器书签快照输入
- 当前思维导图草稿
- WebDAV 云端版本快照
- 本地单份回滚备份
- 草稿撤销历史与周期性 checkpoint

### 7.2 草稿与浏览器写回

- 新增、编辑、移动、删除默认只作用于当前思维导图草稿
- 不自动写回浏览器书签
- 提供“从浏览器覆盖当前草稿”按钮；点击后必须弹出统一确认框，用户确认后才执行覆盖
- 用户点击“同步到浏览器书签”按钮，并确认警告框后，才真正执行浏览器书签写回
- 浏览器写回是覆盖式写回，目标语义是受管范围内浏览器书签与当前草稿一致

### 7.3 显式动作入口

- 右上角直接显示以下 7 个动作按钮，且用户仅通过按钮文字就能理解其含义：
  - 从浏览器覆盖当前草稿
  - 同步当前草稿到浏览器书签
  - 上传当前草稿到 WebDAV
  - 上传当前浏览器书签到 WebDAV
  - 下载 WebDAV 草稿版本到当前草稿
  - 下载 WebDAV 书签版本并覆盖浏览器书签
  - 撤销覆盖操作

当前状态：

- 上述动作按钮当前均已渲染
- 浏览器写回 / WebDAV / 撤销覆盖执行流尚未接入，因此当前保持禁用态

## 8. WebDAV 云端能力

### 8.1 配置

- 首版只支持单一 WebDAV 配置
- WebDAV URL、用户名、密码等连接信息由用户手动填写
- 连接信息保存在扩展本地
- 提供“测试可用性”按钮
- 若 WebDAV 未配置、未授权或不可用，则云端相关功能整体禁用，并提示用户先完成配置

### 8.2 云端版本策略

- 浏览器书签同步到 WebDAV，保留最近 5 个版本
- 思维导图草稿保存到 WebDAV，保留最近 5 个版本
- 浏览器书签快照与草稿快照分开存储
- 云端恢复列表由显式版本索引驱动

### 8.3 恢复语义

- 用户通过两个独立入口分别执行恢复：
  - 下载 WebDAV 草稿版本到当前草稿
  - 下载 WebDAV 书签版本并覆盖浏览器书签
- 两类恢复都采用覆盖语义

## 9. 本地回滚机制

- 任何覆盖式恢复或覆盖式写回执行前，必须先生成对应对象的本地最新备份
- 浏览器书签和思维导图草稿分别维护各自的本地单份备份
- 本地只保留每一类对象的最新 1 份备份
- 右上角提供统一的“撤销覆盖操作”入口
- 点击“撤销覆盖操作”后，用户再二次选择恢复对象：
  - 撤销对浏览器书签的覆盖
  - 撤销对当前草稿的覆盖
- 若两类对象都没有可撤销的覆盖备份，则“撤销覆盖操作”按钮禁用，并在悬浮时说明原因
- 浏览器侧恢复与写回失败采用 `best-effort rollback`
- 失败时优先保护当前草稿不被破坏

## 10. 反馈与状态提示

### 10.1 成功反馈

- 只有在动作执行完成后，界面状态结果区才显示状态结果
- 状态结果区默认贴住当前可视画布右下角，不挤占画布主体宽度
- 状态结果弹窗可最小化，最小化后仍保留半透明“最近记录”入口，点击后可重新展开
- 状态区保留最新 3 条历史记录，按时间倒序展示

### 10.2 失败反馈

- 失败记录同样在动作执行完成后写入状态结果区
- 失败记录至少显示：
  - 操作描述
  - 操作时间
  - 操作结果
  - 简要失败原因
- 支持“可读错误 + 可展开技术详情”的反馈方式

## 11. 非目标

- 首版多浏览器支持
- 多选 / 批量操作
- 自建账号系统或 SaaS 后端
- 多用户与协作
- 复杂智能分类

## 12. 约束

- 核心能力由扩展承载，不依赖远程 URL 网页服务提供核心交互
- 首版前端展示语言固定为中文，但设计与实现必须预留后续多语言扩展空间
- 当前项目不修改外部 workflow 仓库

## 13. 验收标准

说明：以下为产品验收目标，不是当前代码状态说明。

- 能直接读取当前 Chrome 书签树并展示为思维导图
- 节点支持双击编辑；网页节点可编辑 URL
- 节点支持通过 `Enter` 新增子节点
- 节点支持拖拽移动与直接删除
- `Ctrl+Z` 可逐步回退草稿编辑历史
- 展开/折叠状态与布局坐标可本地持久化
- 默认布局可用且美观，并提供一键自动归位
- WebDAV 可配置、可测试可用性、可同步、可恢复
- WebDAV 未配置或不可用时，云端功能禁用且有明确提示
- 同步成功与失败均有清晰反馈
- 始终保留完整且低干扰的操作提示说明区
- 右上角 7 个动作按钮含义清晰
- 4 个覆盖型动作在执行前统一进入确认框
- 状态结果区保留最新 3 条成功/失败历史记录，且支持关闭后重新展开查看
- 首版前端所有用户可见内容均为中文展示
- 当前文案组织方式可支持后续多语言扩展，而不要求大规模重写界面结构
