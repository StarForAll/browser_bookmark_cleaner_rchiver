# 客户向需求文档：界面交互与视觉全面优化

## 概述

为浏览器书签清理与归档器的主工作区进行全面的美化升级，让界面"活起来"——每个交互都有反馈，每个状态变化都有过渡，整体视觉更加精致统一。

## 用户价值

当前界面存在以下体验问题：
1. **交互无反馈**：部分按钮（如顶部操作区、对话框按钮）在鼠标悬停或点击时没有任何视觉变化，用户无法确认操作是否生效
2. **输入框无焦点提示**：使用键盘 Tab 导航时，无法清晰看到当前聚焦的元素
3. **拖拽无区分**：拖拽节点时，被拖拽的节点与静止节点没有视觉区分
4. **弹窗突然出现**：对话框、状态弹窗等突然出现，缺乏平滑过渡
5. **空态单调**：空页面和搜索无结果时，视觉呈现较为单调
6. **滚动条不统一**：不同区域的滚动条样式不一致，影响整体精致感

## 需求范围

### 包含（全量执行）

#### 交互反馈补全
- 所有按钮在鼠标悬停、点击、键盘聚焦时的视觉反馈
- 所有输入框（搜索框、表单输入框）的悬停、聚焦、禁用状态和占位符样式
- 拖拽节点时的视觉区分效果（半透明"幽灵"样式）
- 拖拽放置区在拖拽经过时的视觉反馈
- 禁用按钮的统一样式（半透明 + 去饱和）

#### 视觉增强
- 弹窗打开时的平滑入场动画（slide-up + fade，适中强度）
- 弹窗背景的淡入动画
- 空态页面的精致视觉呈现（emoji 浮动动画 + 文字淡入）
- 回到顶部按钮的出现/消失动画
- 状态弹窗、提示区的淡入动画
- 所有滚动条样式统一（含 Firefox 兼容）
- 错误/警告提示的横幅样式增强
- 列表项悬停时的高亮效果
- 节点图标和 URL 预览在悬停时的增强效果
- 操作提示 tooltip 的滑入效果
- WebDAV 测试结果的状态着色

### 不包含
- 不改变任何按钮或元素的默认外观（颜色、大小、形状）
- 不新增或删除任何功能
- 不涉及移动端触摸交互
- 不修改图谱节点已有的悬停效果

## 验收标准

1. 鼠标悬停在任意按钮或输入框上时，能观察到视觉变化
2. 点击按钮时，能看到按下效果的反馈
3. 使用 Tab 键在界面中导航时，当前聚焦的元素有清晰的焦点标识
4. 拖拽节点时，能明确区分被拖拽的节点和静止节点
5. 弹窗打开时有平滑的动画效果
6. 空态页面有精致的视觉呈现
7. 所有滚动条样式统一
8. 所有交互效果过渡流畅，无闪烁或卡顿
9. 现有功能不受影响，所有测试通过

## 风险与依赖

- 风险：极低 — 仅涉及 CSS 样式修改，不影响功能逻辑
- 依赖：无外部依赖
