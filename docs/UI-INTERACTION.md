# 界面与交互文档

## 1. 目标

本文档描述主工作区页面结构、用户可见动作、图谱交互、对话面、状态反馈和视觉方向。

## 2. 页面模型

主页面是单工作区、单页面扩展应用，不采用正式多路由结构。

持续可见区域：

1. 顶部动作区。
2. 搜索与聚焦区。
3. 图谱画布区。
4. 操作提示区。
5. 状态结果区。

当前已实现：

- 独立扩展工作区壳层。
- 点击扩展图标打开或聚焦工作区页面。
- 五区结构与中文文案。
- 启动阶段本地草稿恢复 / 浏览器导入后的真实草稿图谱渲染。
- 状态弹窗关闭 / 重新打开、状态弹窗开关持久化、最近 3 条状态历史持久化。
- 顶部动作区的浏览器覆盖、浏览器同步、WebDAV 上传、WebDAV 恢复、撤销覆盖和 WebDAV 设置入口。

## 3. 顶部动作区

主动作：

- 从浏览器覆盖当前草稿。
- 同步当前草稿到浏览器书签。
- 上传当前草稿到 WebDAV。
- 上传当前浏览器书签到 WebDAV。
- 恢复 WebDAV 草稿到当前草稿。
- 恢复 WebDAV 书签到浏览器书签。
- 撤销覆盖操作。

次级动作：

- WebDAV 设置。

交互规则：

- 用户应仅通过按钮文字理解动作含义。
- 覆盖型动作统一进入确认流程。
- WebDAV 动作只有在配置有效、host 权限已授予且最近一次可用性检测成功后启用。
- 当前没有草稿时，同步草稿和上传草稿动作禁用。
- 没有可用本地备份时，撤销覆盖动作禁用。
- 有外部动作执行中时，其他外部动作暂时禁用。

## 4. 搜索与聚焦区

- 搜索框支持按标题或 URL 搜索。
- 输入时更新普通搜索命中和图内高亮。
- 按 `Enter` 后聚焦第一个普通搜索结果。
- 搜索框 `↑ / ↓` 在导航激活后循环切换聚焦结果。
- “仅看重复项”切换到重复 URL 聚焦视图。
- 重复 URL 聚焦视图会保留当前搜索词，但不接管普通搜索结果导航。

## 5. 图谱画布

画布表达当前草稿，不直接表达浏览器实时书签树。

当前已实现：

- 目录 / 书签两类节点。
- view-only virtual root。
- DOM + SVG mindmap 渲染。
- 节点标题、URL 预览、子节点计数。
- 拖拽移动、层级重排、顶层提升。
- 悬浮详情、重复 URL 汇总、重复路径展开。
- 深层级宽度适配和低干扰视口提示。

## 6. 节点交互

鼠标与键盘：

- 单击：选择节点。
- 双击：编辑节点。
- 拖拽：移动节点。
- `Enter`：新增子节点。
- `Shift + Enter`：新增同级节点。
- `↑ / ↓`：调整当前层级顺序。
- `←`：提升一级目录层级。
- `Delete / Backspace`：删除节点及其子树。
- `Ctrl+Z`：撤销上一步草稿编辑。
- 悬浮：查看节点详情。

编辑规则：

- 目录节点只能编辑标题。
- 书签节点可编辑标题和 URL。
- 编辑已有节点时不能修改节点类型。
- 书签 URL 不能为空。

删除规则：

- 删除对象包含节点及其子树。
- 删除拥有多个直接子节点的目录时必须二次确认。
- 删除是草稿内操作，不直接写回浏览器书签。

## 7. 覆盖确认

以下动作共享覆盖确认模型：

- 从浏览器覆盖当前草稿。
- 同步当前草稿到浏览器书签。
- 恢复 WebDAV 草稿到当前草稿。
- 恢复 WebDAV 书签到浏览器书签。

确认框必须说明：

- 来源对象。
- 目标对象。
- 将被覆盖的内容。
- 保持不变的对象。
- 覆盖前本地备份规则。
- `Ctrl+Z` 不会撤销外部写操作的提醒。

## 8. WebDAV 设置与恢复选择

WebDAV 设置：

- 单一配置。
- URL、用户名、密码输入。
- 保存设置不会自动视为可用。
- “测试可用性”负责配置校验、host 权限请求和连通性检测。
- 云端动作只在最近一次可用性检测成功后启用。

WebDAV 恢复选择：

- 草稿恢复列表只显示草稿版本。
- 浏览器书签恢复列表只显示浏览器书签版本。
- 选择版本后进入覆盖确认。
- 确认前不会修改当前草稿或浏览器书签。

## 9. 撤销覆盖

- 撤销覆盖不是 `Ctrl+Z`。
- 撤销覆盖只针对最新一份本地备份。
- 草稿备份可用时，允许撤销对当前草稿的覆盖。
- 浏览器备份可用时，允许撤销对浏览器书签的覆盖。
- 两类备份都缺失时，入口禁用并显示原因。

## 10. 状态与反馈

状态结果区：

- 贴住当前可视画布右下角。
- 保留最近 3 条记录。
- 最新记录在最上。
- 支持关闭并通过半透明锚点重新打开。

状态内容至少包含：

- 操作描述。
- 操作时间。
- 操作结果。
- 失败原因。
- 必要的技术详情。

状态规则：

- 动作完成、失败或被阻断后才写入状态。
- 外部动作执行中，其他外部动作显示统一禁用原因。
- 敏感 WebDAV 信息不得出现在状态文案或技术详情中。

## 11. 空态与禁用态

空书签态：

- 空画布不是错误。
- 存在当前草稿时仍可继续编辑、创建、删除和拖拽。
- 状态区说明当前浏览器书签数据为空或导入结果为空。

WebDAV 不可用态：

- 云端按钮可见但禁用。
- 禁用原因指向 WebDAV 设置、host 权限或可用性检测。

撤销覆盖不可用态：

- 按钮可见但禁用。
- 禁用原因说明缺少可恢复备份或备份无效。

## 12. 视觉方向

- 编辑型工作区，而不是后台管理台。
- 画布是视觉焦点。
- 暖亮色基调，低饱和 slate / blue-green 主色。
- 节点卡片应体现“可移动、可编辑”。
- 操作提示和状态浮层低干扰，不遮挡主要操作。
- 避免紫色主导、纯白企业后台感和装饰性过强的页面结构。
