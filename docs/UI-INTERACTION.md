# 界面与交互文档

## 1. 目标

本文档描述主工作区的页面结构、主要交互、关键对话面和用户可见反馈规则。

## 2. 页面模型

主页面是单工作区单页面壳，不采用正式多路由结构。

### 2.1 持续可见区域

1. 顶部动作栏
2. 搜索与聚焦条
3. 主图谱画布
4. 左下角操作提示区
5. 右下角状态结果区

### 2.2 次级界面

- 统一覆盖确认框
- 节点编辑弹层
- 新增子节点弹层
- WebDAV 设置与测试界面
- WebDAV 版本选择界面
- 撤销覆盖目标选择与恢复确认界面

## 3. 顶部动作栏

右上角固定显示以下动作：

- 从浏览器覆盖当前草稿
- 同步当前草稿到浏览器书签
- 上传当前草稿到 WebDAV
- 上传当前浏览器书签到 WebDAV
- 下载 WebDAV 草稿版本到当前草稿
- 下载 WebDAV 书签版本并覆盖浏览器书签
- 撤销覆盖操作
- 自动归位
- WebDAV 测试按钮

规则：

- 用户应仅通过按钮文字就能理解动作
- 覆盖型动作统一进入确认流程
- 云端不可用时，云端动作可见但禁用

## 4. 主图谱画布

- 当前主工作区表达的是草稿，而不是浏览器实时树
- 节点可拖拽移动
- 支持目录与网页两种节点
- 悬浮时显示 URL 与重复信息

## 5. 节点交互

### 5.1 鼠标与键盘

- 单击：选中节点
- 双击：编辑节点
- 拖拽：移动节点
- `Enter`：新增子节点
- `Delete / Backspace`：删除节点及其子树
- `Ctrl+Z`：撤销上一步草稿编辑

### 5.2 编辑规则

- 目录节点：编辑标题，不编辑 URL
- 网页节点：编辑标题和 URL
- 编辑已有节点时不能修改节点类型

### 5.3 新增规则

- 新增时可选择节点类型
- 目录节点不能填写 URL
- 网页节点 URL 必填

## 6. 搜索与重复聚焦

- 支持按标题或 URL 搜索
- 支持重复 URL 过滤 / 聚焦
- 搜索与重复过滤属于界面辅助状态，不进入撤销历史

## 7. 悬浮信息与重复展示

- 节点悬浮时展示 URL 信息
- 若 URL 重复，则展示：
  - 重复总数
  - 前 2 条重复路径
  - 其余项通过“展开更多”查看
- 展示以人可读路径为主，不暴露内部 ID

## 8. 覆盖确认与执行保护

### 8.1 统一覆盖确认面

以下动作共享同一种覆盖确认模式：

- 从浏览器覆盖当前草稿
- 同步当前草稿到浏览器书签
- 下载 WebDAV 草稿版本到当前草稿
- 下载 WebDAV 书签版本并覆盖浏览器书签

### 8.2 双层门禁

- UI 负责确认交互
- 应用层负责最终执行保护、前置检查和阻断

## 9. 状态与反馈

### 9.1 右下角状态区

- 动作完成后才写入状态
- 支持关闭当前结果弹窗
- 关闭后仍保留“最新结果”入口
- 保留最近 3 条记录，最新在最上

### 9.2 反馈内容

成功与失败记录至少包含：

- 操作描述
- 操作时间
- 操作结果

失败还需包含：

- 简要失败原因
- 可展开的技术详情入口

## 10. 左下角操作提示区

- 始终可见
- 低干扰，不抢主图谱焦点
- 一行一条展示核心操作提示

## 11. 空态与禁用态

### 11.1 空书签态

- 空画布不应表现为错误
- 搜索与重复过滤可见但禁用
- 状态区说明当前浏览器书签数据为空
- 草稿编辑与新建能力仍可继续

### 11.2 WebDAV 不可用态

- 云端按钮可见但禁用
- 通过状态区或设置区说明原因

### 11.3 撤销覆盖不可用态

- 按钮保持可见
- 没有可恢复备份时禁用
- 悬浮说明当前原因

## 12. 视觉方向

- 编辑型工作区，而不是后台管理台
- 暖亮色基调
- 低饱和 slate / blue-green 主色
- 画布是视觉焦点
- 节点卡片应体现“可移动、可编辑”
- 避免紫色主导、避免纯白企业后台感

## 13. 自动归位

- 自动归位恢复推荐布局
- 不改变图谱内容或图谱语义
- 布局遵循受控树布局，而不是任意图布局
