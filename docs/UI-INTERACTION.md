# 界面与交互文档

## 1. 目标

本文档描述主工作区的页面结构、主要交互、关键对话面和用户可见反馈规则。

说明：本文档既记录冻结交互目标，也记录当前已实现的壳层状态。除非明确写成“当前已实现”，否则默认按目标交互理解，不应被视为已落地事实。

## 2. 页面模型

主页面是单工作区单页面壳，不采用正式多路由结构。

### 2.1 当前已实现状态

- 已实现单页面扩展工作区壳层和启动引导
- 已实现五个持续可见区域的结构与中文文案
- 当启动阶段存在可编辑草稿时，主画布会直接渲染真实 `DraftGraphWorkspace`
- 已实现状态弹窗关闭 / 重新打开、状态弹窗开关持久化，以及最新启动结果持久化
- 顶部动作和次级动作目前仍为禁用态，不包含真实浏览器写回或 WebDAV 执行；搜索框在存在当前草稿时可用

### 2.2 持续可见区域

1. 顶部动作栏
2. 搜索与聚焦条
3. 主图谱画布
4. 视口右上角操作提示区
5. 当前可视画布右下角状态结果区

### 2.3 次级界面目标

- 统一覆盖确认框
- 节点编辑弹层
- 新增子节点弹层
- WebDAV 设置与测试界面
- WebDAV 版本选择界面
- 撤销覆盖目标选择与恢复确认界面

当前状态：

- 节点编辑弹层、创建子节点弹层、创建同级节点弹层和删除确认弹层已经实现，并在视口允许时按触发节点就近展开
- WebDAV 设置、WebDAV 版本选择、撤销覆盖目标选择与恢复确认界面仍未实现；当前只在动作命名中保留入口语义

## 3. 顶部动作栏

冻结目标动作集合：

- 从浏览器覆盖当前草稿
- 同步当前草稿到浏览器书签
- 上传当前草稿到 WebDAV
- 上传当前浏览器书签到 WebDAV
- 下载 WebDAV 草稿版本到当前草稿
- 下载 WebDAV 书签版本并覆盖浏览器书签
- 撤销覆盖操作
- 重新整理布局
- WebDAV 设置

规则：

- 用户应仅通过按钮文字就能理解动作
- 覆盖型动作统一进入确认流程
- 云端不可用时，云端动作可见但禁用

当前状态：

- 当前动作区已经渲染上述主动作和次级动作按钮
- 当前按钮全部为禁用态，尚未接入真实执行逻辑
- “撤销覆盖操作”会额外渲染禁用原因说明
- `WebDAV 测试按钮` 当前未单独实现，相关能力仍属于后续设置界面范围

## 4. 主图谱画布

- 当前主工作区表达的是草稿，而不是浏览器实时树
- 节点可拖拽移动
- 支持目录与网页两种节点
- 悬浮时显示 URL 与重复信息

当前状态：

- 当启动恢复或导入得到草稿后，当前画布区会渲染真实图谱节点
- 当前已支持目录 / 书签两种节点、virtual root 视图节点、拖拽移动、层级重排与顶层提升
- 当前已支持节点标题、URL 预览、子节点计数，以及包含重复 URL 汇总的悬浮信息展示
- 当前搜索与重复聚焦已经接入到当前草稿工作区

## 5. 节点交互目标

说明：本节描述冻结交互目标；其中一部分已经落地，未特别标注为“当前未实现”的部分可视为当前行为。

### 5.1 鼠标与键盘

- 单击：选中节点
- 双击：编辑节点
- 拖拽：移动节点
- `Enter`：新增子节点
- `Shift + Enter`：新增同级节点
- `↑ / ↓`：调整当前层级顺序
- `←`：提升一级目录层级
- `Delete / Backspace`：删除节点及其子树
- `Ctrl+Z`：撤销上一步草稿编辑
- 搜索框 `Enter`：进入普通搜索结果导航
- 搜索框 `↑ / ↓`：在 `Enter` 激活导航后循环切换当前搜索聚焦结果

当前状态：

- 上述交互当前均已接入
- 删除目录节点时，如果该目录拥有多个直接子节点，会先进入确认框再执行删除
- 当前操作提示中的 `Ctrl+Z` 已连接到 draft-only 撤销历史，不会回退浏览器写回或 WebDAV 动作
- 搜索框导航只作用于普通搜索，不覆盖“仅看重复项”视图

### 5.2 编辑规则

- 目录节点：编辑标题，不编辑 URL
- 网页节点：编辑标题和 URL
- 编辑已有节点时不能修改节点类型

### 5.3 新增规则

- 新增时可选择节点类型
- 目录节点不能填写 URL
- 网页节点 URL 必填
- 当前已支持 `Enter` 创建子节点与 `Shift + Enter` 创建同级节点

## 6. 搜索与重复聚焦目标

- 支持按标题或 URL 搜索
- 支持重复 URL 过滤 / 聚焦
- 搜索与重复过滤属于界面辅助状态，不进入撤销历史

当前状态：

- 搜索与聚焦条作为五区工作区的固定区域始终可见
- 当存在当前草稿时，搜索输入框与“仅看重复项”按钮会启用
- 标题 / URL 搜索当前只匹配节点标题与 URL，不匹配路径文本或内部 ID
- “仅看重复项”会切换到按相同 URL 分组的重复聚焦视图，并保留当前搜索词

## 7. 悬浮信息与重复展示目标

- 节点悬浮时展示 URL 信息
- 若 URL 重复，则展示：
  - 重复总数
  - 前 2 条重复路径
  - 其余项通过“展开更多”查看
- 展示以人可读路径为主，不暴露内部 ID

当前状态：

- 普通节点悬浮会显示标题、节点类型、完整路径
- 书签悬浮会额外显示 URL
- 重复 URL 书签悬浮会显示重复总数、默认前 2 条路径，以及在有更多重复项时显示“展开更多”
- 悬浮关闭后，“展开更多”的展开状态会重置

## 8. 覆盖确认与执行保护目标

### 8.1 统一覆盖确认面

以下动作共享同一种覆盖确认模式：

- 从浏览器覆盖当前草稿
- 同步当前草稿到浏览器书签
- 下载 WebDAV 草稿版本到当前草稿
- 下载 WebDAV 书签版本并覆盖浏览器书签

### 8.2 双层门禁

- UI 负责确认交互
- 应用层负责最终执行保护、前置检查和阻断

说明：本节描述目标门禁模型；当前仓库还没有真实确认框或执行保护实现。

## 9. 状态与反馈

### 9.1 状态结果区

- 动作完成后才写入状态
- 支持将当前结果弹窗最小化
- 最小化后仍保留“最新结果”入口
- 保留最近 3 条记录，最新在最上

当前状态：

- 当前已实现状态弹窗最小化与锚点重新打开
- 当前状态内容会反映真实启动结果：本地恢复、浏览器导入、导入未保存、恢复失败、读取失败、等待导入
- 当前会持久化最新一条启动 / 状态结果以及弹窗开关状态
- 当前状态区固定在当前可视画布右下角；画布底边仍在视口外时，会继续贴住视口底部保持可见
- 当前最小化锚点使用半透明样式，减少对草稿区内容的遮挡
- “保留历史”当前仍只展示最新一条记录，最近 3 条历史保留尚未完全接入

### 9.2 反馈内容目标

成功与失败记录至少包含：

- 操作描述
- 操作时间
- 操作结果

失败还需包含：

- 简要失败原因
- 可展开的技术详情入口

## 10. 操作提示区

- 始终可见
- 低干扰，不抢主图谱焦点
- 一行一条展示核心操作提示
- 使用半透明样式，减少对草稿区内容的遮挡

当前状态：

- 当前该区域已经实现并持续可见
- 当前展示内容与壳层中文文案一致，共 9 条提示
- 当前提示区固定在当前可视画布右上角；画布顶边进入视口顶部后，会继续贴住视口保持可见
- 当前提示区保持半透明低干扰样式，不提供最小化入口

## 11. 空态与禁用态目标

### 11.1 空书签态

- 空画布不应表现为错误
- 搜索与重复过滤在存在当前草稿时可用；这些界面辅助状态不进入撤销历史
- 状态区说明当前浏览器书签数据为空
- 草稿编辑与新建能力仍可继续

当前状态：

- 当前空态会根据启动结果显示“等待导入 / 导入失败 / 本地恢复失败”等真实提示
- 当已经存在草稿时，用户可以继续编辑、创建、删除与拖拽，而不是停留在纯占位态

### 11.2 WebDAV 不可用态

- 云端按钮可见但禁用
- 通过状态区或设置区说明原因

当前状态：

- 当前云端动作按钮可见但禁用
- 当前未实现真实原因计算与设置区联动

### 11.3 撤销覆盖不可用态

- 按钮保持可见
- 没有可恢复备份时禁用
- 悬浮说明当前原因

当前状态：

- 当前“撤销覆盖操作”按钮可见且禁用
- 当前已显示禁用原因文案，但尚未接入真实备份判断

## 12. 视觉方向

- 编辑型工作区，而不是后台管理台
- 暖亮色基调
- 低饱和 slate / blue-green 主色
- 画布是视觉焦点
- 节点卡片应体现“可移动、可编辑”
- 避免紫色主导、避免纯白企业后台感

## 13. 自动归位目标

- 自动归位恢复推荐布局
- 不改变图谱内容或图谱语义
- 布局遵循受控树布局，而不是任意图布局
